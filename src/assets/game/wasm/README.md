# PlayCanvas WebGPU shader transpilers

These files are copied from the PlayCanvas Engine v2.21.4 example assets:

- `glslang/`: <https://github.com/playcanvas/engine/tree/v2.21.4/examples/assets/wasm/glslang>
- `twgsl/`: <https://github.com/playcanvas/engine/tree/v2.21.4/examples/assets/wasm/twgsl>

PlayCanvas loads them only for the WebGPU backend to translate the game's GLSL
custom shaders to WGSL. Keep these files aligned with the installed PlayCanvas
version.
