# Enemy integration contract

Extend `Enemy` from `./Enemy.js`. Constructor takes the production map-object options `{pc, app, definition, runtime, modelLibrary}`. The base places the semantic `entity` root at `definition.position` and applies `definition.rotation`, as required by the object-owned map lifecycle. Attach authored model corrections under a child. Declare static `modelUrls` on the leaf class so normal asset discovery loads only present actors.

`behavior` (also `stateMachine`) is a real `NpcStateMachine` / Yuka StateMachine whose owner is the enemy. Register instances of Yuka `State`, then `changeTo(StateClass.name)`. State `execute(owner)` reads `owner.deltaTime`. Override `update(dt)` only with `super.update(dt)`. `onSceneReady()` creates a dynamic Ammo capsule and subscribes updates; call super if overriding. `moveToward(actor, metresPerSecond, arrivalRadius=0.05)` sets horizontal body velocity, retaining gravity and collisions; use a smaller arrival radius for short planner look-ahead waypoints; `stop()` preserves vertical velocity.

Common capabilities: `isEnemy`, `enemyType`, `alive`, `health`, `maxHealth`, `position`, `stateName`, `testStatus`, `actors`; `receiveDamage(amount, source=null, kind="physical")` and `receiveHealing(amount)` return applied quantities. Dead actors cannot heal or accept statuses. Hooks: `onDamaged({amount,source,kind})`, `onDeath({source,kind})`.

`applyStatus(name, {duration=1, factor?, source?, ...details})` returns acceptance. `statuses` maps names to `{remaining,...details}`. `statusImmunities` may be a Set. Hooks: `onStatusApplied(name,details)`. Subclasses own stun/confusion reactions in Yuka states. `bellImmune=true` prevents bell confusion; optional `onBellEncouraged(source)` may animate anger, never implies a speed increase. `onBellRung({eventId,secondary=false,source,duration=2})` deduplicates events and ignores secondary events to prevent panic-ring recursion. Forward the same eventId for secondary rings.

`resolveRoyalTarget()` discovers actual royal objects through `isRoyal` or production `beginGameOver` capability; it never targets castles. `targetPosition(actor)` resolves active audience model position before root position; `distanceTo(actor)` uses it. Individual enemies must distinguish obstacles from their ultimate royal target. Damage recipients use capability calls rather than importing sibling classes.

`canBeCarriedBy(carrier)`, `beginCarry(carrier)`, `launch({velocity:{x,y,z},thrower=carrier})`, `onLanding(contact)` implement carrier/Ammo flight lifecycle. Hooks: `onCarried(carrier)`, `onLaunched(thrower)`, `onLanded(contact)`. Carrier must expose entity; held position follows it. States should not override flight velocity. `carrier`, `thrower`, `airborne`, `grounded` describe contact lifecycle. Call `super.destroy()` to release subscriptions/body/entity; subclasses release their resources first.

Only create leaf `index.js` once all imports resolve, exporting `EnemyObjectClass`. Factory discovers `./enemies/*/index.js` eagerly and validates subclasses; no renderer branches and no normal spawn pools. Test actors belong exclusively to each saved enemy test map.
