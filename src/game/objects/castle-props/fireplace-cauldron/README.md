# FireplaceCauldron

Reusable authored cauldron placed through a map's `objects` array with
`object: "FireplaceCauldron"`.

Position is the bottom-center pivot. Standard rotation, tilt, scale, stretch,
and weathering use the shared authored-prop lifecycle, including mesh collision,
island movement, render batching, and cleanup.

The editable model remains in `src/game/models/castle/props/fireplace-cauldron.blend`
with its adjacent GLB. The transparent preview comes from the production renderer
on `/en/map/test_castle-props-1`.
