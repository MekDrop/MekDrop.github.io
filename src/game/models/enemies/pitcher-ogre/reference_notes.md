# Pitcher Ogre reference review

Primary local design sheet: `src/game/objects/enemies/pitcher-ogre/info.png`. Only its large upper-left blue ogre defines identity. The text and secondary Crab/Divecap/Doorcracker/Gobbler cameos were not used as substitute character artwork.

`tripo-reference.png` is a retained ImageGen-derived clean portrait, uploaded to Tripo Studio with the user's explicit design-image authorization. Prompt: extract the upper-left main blue cubist ogre, enormous faceted grey stone fists, broad blue torso/arms, short blue legs, yellow/black eyes, open dark mouth with white teeth and pink tongue, brown belt/loincloth and square gold buckle; remove lettering, panels, secondary figures, floor, loose rocks and shadows; preserve proportions and three-quarter orientation. This derived source is separate from the unchanged info.png.

The Tripo result closely follows that visible silhouette and palette. Its rear is generated inference. Fixed original front/profile/rear/isometric renders were inspected in `tmp/pitcher-ogre/`; final imported-action contact sheets are retained with the object under `evidence/`. The mesh and texture remain Tripo's; local changes repair binding, stiffness/weights and motion rather than replacing the design with primitive artwork. Grounded game scale and the animated carrier attachment must still be confirmed in the production scene.

The invalid provider rig is retained under source/tripo-rigged.* for provenance, not used by runtime. The final model contains the bespoke 16-bone anatomical rig; source GLB/bindings and all 22 actions are covered by focused offline checks. No paid replacement generation was warranted by the neutral appearance review.
