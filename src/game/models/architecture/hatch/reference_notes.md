# Hatch lock

The rim lock uses a lid-mounted iron case with a downward-facing keyway and a separate keeper secured to the inner face of the fixed timber frame. The bolt retracts into the case when unlocked. The keeper remains stationary as the lid opens.

Mechanical reference: [antique cast iron rim lock and separate keeper](https://www.historichouseparts.com/antique-cast-iron-horizontal-rim-lock-with-keeper-made-by-russell-and-erwin.html). Reference inspected for case, keyway, fixing and keeper construction; no third-party mesh or image is included.

`rim-lock.blend` and `rim-lock-keeper.blend` are the editable sources for the adjacent GLBs. Units are metres. Runtime mounting coordinates use Y up, with the bolt extending towards positive Z.
