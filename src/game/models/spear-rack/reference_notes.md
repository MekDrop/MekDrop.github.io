# Reference observations

- [Styrian Armoury polearms](https://www.museum-joanneum.at/en/about-us/press/exhibitions-and-projects/event/styrian-armoury-2), official photograph Landeszeughaus_Dauerausstellung_19.jpg, viewed 2026-10-15: dense upright shafts, dark iron blades, shared lower and waist-height timber guides. Museum photography is reference-only and is not included in shipped artwork.
- [Pike collection](https://www.museum-joanneum.at/en/styrian-armoury/discover/collection/staff-weapons/pike): identifies 16th/17th-century stored pikes and explains shortened historical shafts.
- [Rijksmuseum NG-BR-554](https://www.rijksmuseum.nl/en/collection/object/Spear-Rack-of-Governor-General-JC-Baud--2925f555bbb8aca0b5c017e2e430dd7d), 1834: teak/brass rack; catalogue describes oval cutouts and guide rings. Useful evidence for positive shaft guides rather than shafts intersecting rails. Its decorative arch is not copied.
- [Himeji castle photograph](https://commons.wikimedia.org/wiki/File:Racks_of_antique_yari_and_tanegashima.jpg): viewed horizontal wall-mounted spear storage; useful as a contrasting storage method, not evidence for the proposed upright multi-row frame.

The unified three-row frame is a historically informed game design, not a claimed exact reconstruction. Runtime scale preserves the existing game envelope. The concept defines shared base, cross-connected end frames, open comb slots, warm oak, broad leaf blades and iron joinery. Only newly authored Blender geometry and materials ship.
