# Tripo appearance comparison

`hero-tripo.blend` preserves the generated, textured static character as editable
source; `hero-tripo.glb` is exported from it. The model is scaled to the current
hero's head-to-sole height for comparison. Generation used 30 Tripo credits;
the job, reference hash and normalization are recorded in `provenance.json`.

This candidate is not used by the playable hero. It has no rig or animation.
Its rounded face, hair and clothing do not match the game's deliberately
constructed cubist forms. Keep the production hero and its articulated gloves
as the accepted game model. Local voxel-remesh and flat-shading experiments
were rejected because they added stair-stepping or triangular facets without
recovering the intended broad block shapes.
